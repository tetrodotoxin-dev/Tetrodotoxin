# Foundation notices

These files are copied verbatim from the headers archives of TTX 0.2.0 and
Perimortem 0.1.0, whose URLs and checksums are declared in `MODULE.bazel`.
They accompany the matching binaries in the native runtime bundle.

Toolchain's SDK importer exposes library and header targets but does not export
the archived license files as Bazel labels. Keeping the exact notices here makes
packaging independent of the importer's private repository layout. Review them
when changing the corresponding dependency pins.
